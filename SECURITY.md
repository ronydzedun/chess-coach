# Security policy

Chess Coach is an early-stage local desktop application. Please report security issues with enough detail to reproduce and assess them, while avoiding disclosure of personal data or information that could put other users at risk.

If GitHub private vulnerability reporting is enabled for the repository, use that channel. Otherwise, open a public issue with a high-level description and reproduction that does not include exploit details or sensitive data; ask for a private contact route in the issue. Do not post secrets, personal data, or weaponized proof-of-concept material publicly.

There is no guaranteed response or remediation timeline yet. This policy will be updated when a maintained private reporting channel is established.
