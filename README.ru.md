# Chess Coach

Chess Coach — локальное настольное приложение с шахматной доской для игры и разбора ходов. Это ранняя версия приложения на Rust под лицензией GPL-3.0-or-later.

![Chess Coach analysis](assets/screenshots/analysis-linux.png)

Работающее приложение: локальный анализ Stockfish на Debian 13 (X11/Xvfb).

## Возможности

- Чтобы сделать ход, нажмите на фигуру, затем на поле назначения. Доска подсвечивает выбранную фигуру, допустимые поля и последний ход.
- При превращении пешки можно явно выбрать фигуру. Правила, включая шах, мат, пат, рокировку и взятие на проходе, реализованы с помощью `shakmaty`.
- Просматривайте список ходов в стандартной алгебраической нотации (SAN), отменяйте ход, начинайте новую партию и переворачивайте доску.
- Загружайте позицию в формате FEN и копируйте текущую FEN. При ошибке загрузки текущая позиция и история сохраняются.

Для локального анализа отдельно установите Stockfish или другой движок с поддержкой UCI и укажите его исполняемый файл в приложении. Приложение также использует `STOCKFISH_EXECUTABLE`, ищет движок в `PATH` и проверяет `/usr/games/stockfish`. Можно задать время анализа в миллисекундах или глубину поиска. Оценки в сантипешках и матах показываются с точки зрения белых, а главный вариант — в координатной нотации UCI. Движок не входит в поставку. Импорт и экспорт PGN, сохранение партий, облачные и ИИ-сервисы не входят в текущую версию.

## Сборка и запуск

Установите Rust через `rustup`; в `rust-toolchain.toml` закреплена версия Rust 1.99.1. В Debian 13 установите системные пакеты для разработки и библиотеки X11/Wayland:

```sh
sudo apt install build-essential pkg-config libwayland-dev libxkbcommon-dev \
  libx11-dev libxcursor-dev libxi-dev libxrandr-dev libxkbcommon-x11-0
```

Из корневого каталога репозитория запустите приложение:

```sh
cargo run --locked -p desktop --bin chess-coach
```

Приложение использует UI-библиотеку `iced` 0.14 с программным рендерером `tiny-skia` и нативными бэкендами Wayland/X11. Рендерер Vulkan или `wgpu` не используется.

## Stockfish и управление

В Debian отдельно установите движок: `sudo apt install stockfish`. Обычно его путь — `/usr/games/stockfish`. Для других ОС загрузите подходящий исполняемый файл с [официального сайта Stockfish](https://stockfishchess.org/download/). Укажите полный путь в боковой панели или задайте переменную `STOCKFISH_EXECUTABLE` перед запуском. Пробелы в пути допустимы; раскрытие `~` и других shell-выражений не выполняется. Без движка доска и FEN продолжают работать.

Выберите **Time (ms)** (1–300000 мс) или **Depth** (1–128), затем **Analyze**. Кнопка **Stop** останавливает поиск. Изменение позиции отменяет анализ и очищает прежнюю оценку. У анализа по глубине есть защитный предел 60 секунд. Положительная оценка означает преимущество белых, отрицательная — чёрных. `M+3` означает мат со стороны белых в три хода, `M-3` — со стороны чёрных. Для `M0` указан победитель. Лучший ход и вариант показаны в координатной нотации UCI.

Ctrl/Cmd+N — новая партия, Ctrl/Cmd+Z — отмена, Ctrl/Cmd+F — переворот, Escape — отмена выбора или превращения. Ввод FEN подтверждается Enter. Аккаунты, телеметрия, сетевые службы и внешние API для работы не нужны.

## Проверки и ограничения

```sh
cargo build --workspace --all-targets --locked
cargo fmt --all -- --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
```

Для тестов с настоящим движком: `STOCKFISH_EXECUTABLE=/usr/games/stockfish cargo test -p engine --locked -- --nocapture`. Основные тесты обходятся без Stockfish.

Приложение запущено на Debian 13 + Hyprland в нативном Wayland. Интерфейс также проверяется через X11/Xvfb. При необходимости явно выбрать Wayland можно запустить `env -u DISPLAY cargo run --locked -p desktop --bin chess-coach` из работающей Wayland-сессии. Настройки Hyprland менять не требуется. Сборка и запуск выполняются обычным пользователем; root нужен только для установки системных пакетов.

Весь workspace прошёл кросс-проверку `cargo check` для Windows GNU и macOS Darwin; нативная сборка, тесты и запуск на этих ОС пока не подтверждены. CI настроен для трёх ОС; сам факт настройки не означает успешного выполнения.

Ограничения прототипа: ходы двумя кликами без drag-and-drop, один вариант анализа, нет автоматического соперника, импорта PGN, интерфейса заявления ничьей по повторению/50 ходам, сохранения партий, тренировок и ИИ-наставника. После загрузки FEN список ходов начинается заново. Фигуры используют встроенный лицензированный DejaVu Sans; отображение на Windows/macOS ещё не проверено.

## Состав workspace

- `chess-core` — состояние стандартной шахматной партии и нотация с транзакционным применением ходов.
- `engine` — асинхронная служба локального UCI-движка.
- `desktop` — приложение `chess-coach`.
